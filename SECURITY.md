# Security

Report vulnerabilities privately through this repository's **Security → Report a
vulnerability** form. Include the package version, Umbraco release, reproduction steps
and impact. Keep details out of public issues until a fix is available.

Fixes are published for the supported Umbraco releases listed in the README. Install
the newest package for your site's major version to receive them.

This package removes Umbraco's built-in telemetry job through dependency injection.
For vulnerabilities in Umbraco itself, follow
[Umbraco's security policy](https://github.com/umbraco/Umbraco-CMS/security/policy).
