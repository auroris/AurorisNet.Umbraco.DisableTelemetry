# Security

Report a vulnerability in private, with
[GitHub's vulnerability report form](https://github.com/auroris/UmbracoDisableTelemetry/security/advisories/new),
also under **Security → Report a vulnerability** in this repository. Keep the details out of
public issues until a fix is published. Include the package version, the site's Umbraco
release, the steps that show the problem and what someone gains by it.

A fix is published as a new package version for each supported Umbraco major version, as
the [supported-versions table](README.md#supported-versions) lists. Install the newest
package for your site's Umbraco major version to get it.

For a vulnerability in Umbraco itself, follow
[Umbraco's security policy](https://github.com/umbraco/Umbraco-CMS/security/policy).
