# Security

## Report a vulnerability

Report a vulnerability in private, with
[GitHub's vulnerability report form](https://github.com/auroris/AurorisNet.Umbraco.DisableTelemetry/security/advisories/new),
also under **Security → Report a vulnerability** in this repository. Keep the details out of
public issues until a fix is published. Include:

- the package version and the site's Umbraco release;
- the steps that show the problem, and what someone gains by it.

## Versions that get fixes

A fix is published as a new package version for each Umbraco major version in the
[Supported versions table](README.md#supported-versions). Install the newest package for
your site's Umbraco major version to get it.

## What the package covers

Report here a vulnerability in the package's replacements for Umbraco's telemetry job,
installer report service and news dashboard service. For a vulnerability in Umbraco itself,
follow [Umbraco's security policy](https://github.com/umbraco/Umbraco-CMS/security/policy).
